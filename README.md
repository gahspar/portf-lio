# PM Developer Systems — Portfólio

Portfólio institucional da PM Developer Systems, desenvolvido com Next.js, React e TypeScript.

O site apresenta projetos reais em um carrossel contínuo, serviços oferecidos pela empresa e chamadas diretas para contato pelo WhatsApp.

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Lucide Icons

## Executar localmente

Requisitos: Node.js 22 ou mais recente.

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Compilação de produção

```bash
npm run build
npm run start
```
